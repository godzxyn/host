# ZxYn Premium Hosting Bot

## Start command
python zxyns1.py

## Required environment variable
`BOT_TOKEN` = Telegram BotFather token

## Python dependencies
- pyTelegramBotAPI
- psutil

## Important
This bot runs with long polling and is intended for a worker/background service. Do not commit `.env`, `users_data.json`, or `bot_settings.json` to a public repository.
